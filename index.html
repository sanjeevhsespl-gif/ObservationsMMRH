          How to use this app

          Self-contained HSE observations tool for KFM / Khansaheb at KEZAD / Al Ma'Mourah. No login. Data is stored in this browser (localStorage) and can be backed up as JSON.

          1. Add or edit observations

          1. Open the Observations tab.
          2. Click + Add observation (or Edit on a row).
          3. Fill Date, Zone (KP4–KP9), Location, Lat/Lng if known, Observation, Category, Risk Level, Corrective Action, SR No, WO No, Status, and optional assignment / close dates.
          4. Save. Dashboard and map update automatically.

          2. Upload closeout photos (Before / During / After)

          1. Open Photos & Closeout.
          2. Select a Work Order.
          3. Upload three images: Before, During, After.
          4. When all three are present, the WO becomes Closeout Ready and export buttons unlock.

          3. Export closeouts for Maximo attachment

          1. Only Ready WOs can export.
          2. Export PDF — branded print-ready closeout with logos and the three photos.
          3. Export Excel — branded .xlsx with WO/SR/location/observation/risk/action and embedded photos.
          4. Batch export all ready — downloads each ready WO as PDF and Excel.
          5. Attach the PDF (and/or Excel) to the Maximo work order.

          4. Map

          Observations with coordinates show as risk-coloured pins. Rows without GPS stay off the map. Use the Google Maps links list for navigation.

          5. Persistence & reset

          • Changes persist in browser storage across refreshes.
          • Export JSON downloads a full backup.
          • Reset to seed reloads the original 20 observations (clears edits and photos).

          Run locally

          Open index.html directly, or from this folder:

          python3 -m http.server 8765

          Then visit http://localhost:8765
